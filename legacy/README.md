# Legacy Frappe-hosted implementation

This directory contains the previous implementation, which was installed as a Frappe app and served MCP over a whitelisted Frappe HTTP endpoint. It is kept for source/history reference only.

The standalone package does not import or distribute this code. Do not install the legacy app when using the current MCP server. Its historical validation report remains in `../e2e/REAL_HTTP_REPORT.md`.
